## 7. 一致性冻结检查

实施前和发布前都必须确认：

1. `REQUIREMENTS.md` 未被修改。
2. 样本统一为 2018-01-01—2025-12-31，探索/确认分期一致。
3. 全文使用 `usable_from`，不假装源数据提供历史 `available_at`。
4. 信号在数据更新后形成，满足时间不等式。
5. 复权公式、标签、组合收益与成本时点一致。
6. 九端点矩阵、探测、请求估算、缓存和回退一一对应。
7. `limit_status`、`stk_limit`、`suspend_d` 语义未混用。
8. 次日开盘成交与延迟订单规则一致。
9. H00300 未被当作未经探测的 API 代码。
10. 总收益/价格指数标识和股息处理一致。
11. 确认揭示、研究决策、复现运行与污染定义一致。
12. REG 不以盈利为成功条件。
13. Pages 是 P0，PDF 是 P1 且不阻断核心。
14. Token、原始数据和公开许可边界一致。
15. 验收主体是用户本人加自动化；外部用户仅为未来指标。
16. `AI_PROMPTS.md` 保留既有提示词并追加本轮原文。
