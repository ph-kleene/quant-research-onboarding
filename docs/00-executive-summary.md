# 00｜执行摘要

## 一句话定稿

本项目将交付一套可公开发布、可离线运行、可复现验证的中文量化研究入门产品：学习者沿 20 个步骤完成一个沪深 300 三因子案例，同时学会识别数据、时点、成本、样本外与复现风险，并用研究评审门（REG）判断结论是否可信。

## 唯一推荐方案

采用“Quarto 学习站点 + 可执行 Notebook + 模块化研究管线 + 自动化测试 + GitHub Pages”的组合方案。正式案例以真实 Tushare 数据为主线；确定性教学数据仅用于单元测试、离线接口失败演示和无 Token 的产品预览，不替代正式研究结论。

## P0 主交付物

1. 公开 GitHub 仓库与 GitHub Pages 中文学习站点。
2. 可离线打开的完整 HTML、可执行 Notebook、研究源文件、测试、构建与复现说明。
3. 沪深 300 三因子案例：2018-01-01 至 2025-12-31；探索期为 2018-01-01 至 2022-12-31，确认期为 2023-01-01 至 2025-12-31。
4. 20 步学习路径和 30 分钟、3 小时、深入学习三条路线。
5. 数据能力矩阵、九个 Tushare 端点的实施前探测方案、缓存清单与数据护照。
6. 正确示范与失败实验双轨、研究评审门（REG）、确认期治理与污染记录。
7. 保守的次日开盘成交模型、真实成交时点成本、延迟成交统计和对齐基准。
8. 自动化测试、Notebook 端到端执行、离线构建、链接/视觉/README 冷启动检查。
9. 提问模板、失败诊断模板、研究护照和完整 AI 提示词档案。
10. 公开发布前安全与许可审计。

PDF 是便利性 P1；其生成失败不得阻断 HTML、Notebook、研究管线或 Pages 发布。

## 首屏与学习结果

README 首屏必须回答：这是什么、站点入口、如何本地运行、三条学习路径、数据权限、无 Token 行为、Token 更新方式、非投资建议，并展示关键截图。完成课程后，学习者应能解释数据何时可用、为什么信号不能在收盘瞬间形成、如何避免未来函数、交易成本和成交受限如何改变结果，以及为何“策略不赚钱”仍可能是合格研究。

## 已锁定的实施条件

- 环境由 uv 管理，并由 uv 安装固定 CPython 3.12；不得沿用当前 WSL 的系统 Python 3.14.4。
- 实施阶段安装 Quarto、Python 构建/测试依赖；如 PDF 有明确价值，可再安装浏览器或 TinyTeX。
- 优先用户级安装，仅在确有必要时使用 sudo；所有关键版本写入研究护照。
- 统一入口预定为 `bash scripts/project.sh setup|test|build|preview`，README 不暴露零散命令。
- Tushare 默认限速不高于 180 次/分钟，成功缓存不可变，任务可续跑，429 使用退避重试。
- Token 只从 `TUSHARE_TOKEN` 或 `~/.config/shangchen-quant-research-onboarding/tushare.env` 读取；仓库不存密钥或原始授权数据。
- 月末信号仅在 P0 数据更新后于固定晚间时点形成，默认 18:00；随后一个有效交易日开盘执行。

## 成功定义

成功不等于正收益。P0 成功意味着：真实数据路线可探测、研究时钟一致、结果可复现、失败能被解释、用户能独立完成八步自测、站点可公开访问且安全审计无阻断项。REG 的数据、时序或复现维度为红色时，研究结论无效；统计、成本或稳健性维度失败时，可以形成可信的“补充研究/停止”结论，教学项目仍可成功。

## 主要风险与唯一降级规则

- 某端点无权限：只启用该能力在数据矩阵中预先指定的降级，不把教学数据冒充真实研究数据。
- 总收益指数不可用：改用实际探测成功的沪深 300 价格指数并明确标注；相对价格指数超额收益不作为唯一 REG 硬门。
- Pages 暂时不可用：先交付离线 HTML 并记录阻断，恢复后补齐 Pages；不删减课程与研究核心。
- PDF 工具链不稳定：延后 PDF，不阻断 P0。
- 公开发布发现密钥或许可风险：立即停止推送/发布，轮换密钥、清理历史并重新扫描。

## 24 小时背景的处理

24 小时是原始规划背景，只用于排序和估时，不是删减核心功能的触发器。P0/P1、验收门和逐能力降级规则保持有效；实际实施以质量门通过为完成条件。
